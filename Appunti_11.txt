Query nidificate

Query 1
select fy.codf
from f fx, f fy
where fx.sede = fy.sede and fx.codf = 'f1'

Per risolvere questo esercizio si possono usare le query nidificate

select codf 
from f
where sede = (select sede
            from f
            where codf = 'f1')

Query 4


select nomef
from f 
where codf in (select codf
                from fp
                where codp in (select codp
                                from p
                                where colore = 'Rosso'))
